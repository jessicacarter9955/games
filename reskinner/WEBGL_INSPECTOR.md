# Unity/WebGL inspection V1

The local diagnostic bridge is injected before original game scripts by the mirror server. It now tracks texture uploads and, only during inspect mode, WebGL draw counts and requested downsampled frames. The inspector shows a color-connected region or a small explicitly manual region rather than the whole canvas; clicking pins and permits bounding-box edits. The screenshot crop is not an original texture. The object explorer lists observed GPU textures independently; a source URL is reported only if directly exposed by the upload. No mapping between pixels and GPU textures, GameObject identity, Unity scene hierarchy, asset extraction, or live replacement is claimed. Unreadable frames and missing early hooks are reported as such. No game builds or render state changed. Reload a local game to activate the new bridge. Test: node scripts/test_webgl_inspector.mjs.
