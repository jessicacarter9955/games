# 2Night Game Factory — decision record (2026-11-28)
- Originals are immutable: preserve captured ZIPs, mirrors and master assets. Reskins are distinct branches per game; checkpoints are read-only copies. Never overwrite original data.
- Initial test: Candy Clicker 2; then basketball prototypes (Tap-Tap Shots, Flappy Dunk) and idle engine. Build original implementations and use only authorized assets/code.
- Asset generation in ChatGPT first; no paid image API prerequisite. Preserve original high-resolution master; derive optimized texture atlases and responsive variants separately. Classify semantic function, artistic style, iconography, palette, materials, animation, provenance/license.
- AI context export: screenshot/crop, semantic element ID, geometry, source asset, scene/interaction inventory; compare before/after. Preserve original proportions and behavior unless responsiveness requires change.
- Benchmark Defold (native Android/iOS + HTML5, source-available) first; Godot MIT alternative; avoid WebView where feasible. Single codebase preferred only if measured results meet budget.
- Target initial web transfer 1–3 MB, simple game total 5–10 MB, native download 5–15 MB, first meaningful input 1–3 s on good connection, 60 FPS on reference hardware. Measure actual compressed transfer, cold-start, frame time, peak memory, device-specific behavior; progressive asset/level loading. Targets, not guarantees.
- Reference: https://defold.com/2026/09/07/Interview-Green-Train-Playgama/ ; https://developers.google.com/youtube/gaming/playables/certification/requirements_stability ; https://docs.crazygames.com/requirements/technical/
- Responsive QA: small phone, modern phone, tablet portrait/landscape, laptop, FHD/QHD/4K, ultrawide, safe areas, touch/mouse.
- Current versioning: browser-local branches with per-branch IndexedDB PNG patches, named checkpoints and full JSON package export. Original reads are never patched. Comparison runs two independent frames, but original game save storage may be shared by the engine on this origin; two Unity instances may be expensive. Embedded Unity textures still require a dedicated adapter. No automatic GitHub push of generated assets yet; export and commit packages separately. Existing unscoped drafts preserved as read-only legacy branch. Scope is explicit on top-level game iframe; nested iframe/worker patching is deliberately not assumed.
- User manually certifies gameplay; never equate initialized runtime with playable game.
